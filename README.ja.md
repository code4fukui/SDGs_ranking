# SDGs_ranking

このプロジェクトは、日本の都道府県ごとのSDGs（持続可能な開発目標）の認知度および施策認知度スコアを可視化します。

## デモ
https://code4fukui.github.io/SDGs_ranking/

## 機能
- 日本の都道府県ごとのSDGs認知度および施策認知度スコアを可視化
- オンラインレポートからスクレイピングしたデータを使用
- インタラクティブマップ上で表示する指標を選択可能

## データ / API
本プロジェクトでは、以下のオンラインレポートからスクレイピングしたデータを使用しています。
- [都道府県別のSDGs認知度ランキング＜2021＞ | 新・公民連携最前線 | PPPまちづくり](https://project.nikkeibp.co.jp/atclppp/PPP/report/090200284/)
